## Software in the Grid

[Software in the Grid](https://www.softwareinthegrid.com/) is where I publish my main technical work.

The central question is:

> **How does software actually work inside modern power infrastructure?**

Topics include:

- grid and substation software
- IEC 61850 and IEC 60870-5-104
- SCADA and OT systems
- industrial networking
- cybersecurity in critical infrastructure
- distributed systems, reliability, and testing
- software architecture around physical infrastructure

I also write **Software Foundations** pieces about networking, Linux, TLS, protocols, and other systems from first principles. These are the foundations underneath the grid software work, not a separate direction.

## How I like to learn

A lot of my projects follow the same method:

1. Take a system that normally looks like a black box.
2. Rebuild a simplified version.
3. Find out why the mechanisms and constraints exist.
4. Turn the result into code, diagrams, experiments, and explanations.

That is how projects about TLS, cryptography, web servers, networking, time, testing, and power infrastructure fit together.
