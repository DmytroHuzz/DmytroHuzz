# Dmytro Huz

I build software and write about systems that are easier to use than they are to understand.

Most of my public work follows the same pattern: take a black box, rebuild enough of it from scratch, then turn the result into code, diagrams, and practical mental models. TLS, block ciphers, MACs, tiny web servers, time, electrical grids, and developer tooling all fit that pattern.

## what I work on

- Full-stack engineering with TypeScript, Python, React, Docker, and CI/CD.
- QA and DevOps systems for software where reliability matters.
- First-principles explanations of security, infrastructure, and developer workflows.
- Small tools and interactive demos that make abstract ideas concrete.

## writing

I publish [Rebuilt](https://www.dmytrohuz.com/), a Substack for developers who like taking complex systems apart and rebuilding the useful mental model.

Recent themes include:

- rebuilding cryptography and TLS from scratch
- developer-friendly explanations of electricity and grid systems
- practical mental models for time, security, and infrastructure
- tools that connect requirements, code, and tests

## current interests

- Making critical infrastructure software easier to reason about.
- Building QA systems that prove tests would catch real failures.
- Turning deep technical topics into articles, diagrams, and runnable demos.
- Using AI as leverage inside real engineering workflows, not as a substitute for judgment.
